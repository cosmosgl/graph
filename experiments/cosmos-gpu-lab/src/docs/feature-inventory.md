# Feature inventory data

The WebGPU migration page reads these rows for the checklist, counts and search results.
Give each feature its production behavior, coverage status, main gap and links to the relevant findings.

## Simulation

| Feature | Production WebGL | Coverage | Evidence and remaining validation |
| --- | --- | --- | --- |
| **Gravity** · `simulationGravity` | A fragment per point computes a linear pull toward the fixed world origin, scaled by strength and simulation temperature (`alpha`). | Partial | The [refined gravity candidate](#/combined-layout?section=doc-gravity-trig) and [combined CPU checkpoints](#/integrated-webgpu?section=doc-composed-interaction) pass bounded M3 checks. Validate production settings and other devices. |
| **Center** · `simulationCenter` | Points blend position sums and count into a 1×1 floating-point target. A second pass divides by count and pulls each point toward the current centroid. | Partial | The [high/low reduction](#/collision?section=doc-findings) fixes the observed dense-center error. Validate longer runs with broader settings on other GPUs. |
| **Many-body repulsion** · `simulationRepulsion` | Up to 4,096 points, checks every pair. Larger graphs use hierarchical grid sums/counts for distant contributions and depth-selected samples of actual points for nearby contributions. | Partial | The [packaged forces](#/production-forces?section=doc-results) cover exact and hierarchical repulsion. The [archived prototype](#/layout-acceptance?section=doc-findings) exercised the cutoff and resize. Verify the boundary through both packages and measure runtime sampling, layout quality and frame cost across graph shapes. |
| **Link springs** · `simulationLinkSpring` | Adjacency textures describe each point's neighbors. Each fragment accumulates ordered spring corrections using rest lengths, degree bias and strength. Incoming and outgoing passes each integrate before the next starts. | Partial | [Weighted springs](#/weighted-links?section=doc-results) pass bounded reference checks. Three large hubs match CPU checkpoints at 32,768 points but miss frame and pick targets. Validate ordered updates and larger multi-hub topologies. |
| **Cluster attraction** · `simulationCluster` | Additive blending computes a center per cluster. Points read that center or an explicit cluster target and apply global and per-point attraction strengths. | Partial | The [large-group reduction](#/integrated-webgpu?section=doc-composed-interaction-native-resident-results) matches CPU sums for 131,328 present points. The stage costs about 28 ms in the million-point run. Validate production setters and sustained layouts. |
| **Per-point attractors** · `simulationAttractor` | A texture stores target coordinates, strength and target presence. Each fragment pulls its point toward its target; missing targets contribute zero. | Partial | [Signed strengths and missing targets](#/point-attractors?section=recorded-findings) pass through 8,192 points on M3. Validate production setters, transitions and longer runs. |
| **Mouse repulsion** · `simulationRepulsionFromMouse` | A fragment per point computes inverse-square repulsion from the pointer with a minimum-distance clamp. It can run independently of the main simulation. | Partial | [Pointer input in the composed viewer](#/integrated-webgpu?section=doc-composed-interaction) matches CPU with corrected arithmetic. Measure responsiveness and force cost at scale. |
| **Collision** · `simulationCollision` | Up to 4,096 points, resolves every pair. Larger graphs use spatial hashing with depth-selected neighbor slots. Radius-weighted positional corrections integrate with friction 1 and may repeat per tick. | Partial | [Hashed collision](#/collision?section=doc-hashed-findings) matches WebGL slot IDs in bounded tests. [Two passes](#/integrated-webgpu?section=doc-composed-interaction) match CPU checkpoints through 32,768 points and cost about 168–173 ms at one million. The WebGPU grid uses the largest resolved point size so an unused default preserves the layout. Verify production seed parity and dense motion at scale. [Collision grid sizing](#/production-force-collision?section=doc-results-collision-grid-sizing) |
| **Integration and friction** | A separate pass applies the correction, preserves pinned/absent points and guards invalid or excessive steps; position textures are swapped before writing. | Partial | The [corrected integrator](#/combined-layout?section=doc-gravity-trig) passes selected trajectories. Verify the numerical guards with all production forces. |
| **Cooling and lifecycle** | CPU scheduling updates alpha, controls stepping/pause/resume and emits lifecycle callbacks. | Partial | [Two 5,000-tick full-force runs](#/integrated-webgpu?section=doc-composed-interaction) stayed stable and reheated at 8,192 points. Exercise production callbacks and long runs at larger sizes. |
| **Pinning and dragging** | Pin status prevents integration from moving a point; dragging writes its position through a GPU pass. | Partial | [Pointer dragging and pin restoration](#/integrated-webgpu?section=doc-findings) work in the pilot. Validate their behavior with the full force set and production input handling. |
| **Point-count and position updates** | Typed-array positions establish stable indices; NaN marks absence. Rebuilt storage reapplies the CPU pinned-index set; setters can transition coordinates and visual channels. | Partial | [Copy during rebuild](#/point-buffer-copy?section=doc-findings) preserved indices, pins and absent points in bounded checks. [Buffer reuse](#/point-capacity?section=doc-method) measures removal time and retained memory. [Live edits](#/resident-layout-edits?section=doc-method-recorded-check) kept the position buffers through point and link changes. Validate production setters, transitions and memory retention. |
